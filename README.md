# petri-dish-sim

Petri Dish Lab is a simple game inspired by pixel based games, like one of my favorites orb.farm! 

Visitors can drag and drop various ingredients on the active petri dish area and watch their cultivated biomes grow and see how the ingredients interact with each other. When a visitor is done creating, they can hit 'record findings' to download a short video clip and share their artistic discoveries with other petri dish researchers.  

This website was made as a quick discovery session and vibecoded with the help of Claude.
